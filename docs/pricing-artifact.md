# Canonical pricing artifact

`app/subscription-offers.json` is generated by contracts `cmd/plancatalog`; do
not edit prices by hand. `npm run pricing:check` compares exact generator output
from pinned published contracts v0.1.111 and is a CI release gate. Updating the
pin and generated artifact together is required when canonical offers change.
For local unpublished contracts work, set `ENVPLANE_CONTRACTS_DIR` to that checkout.

The page displays catalog offers, including Community and negotiated Enterprise;
displaying an amount does not create checkout eligibility. Provider Price IDs,
provider credentials and the seller registry are not website data.

Local PAY-002 checks: pinned and local-source drift checks, ESLint and TypeScript
passed on 2026-10-11. No website publish or hosted CI run was performed.
